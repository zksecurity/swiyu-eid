# Synthetic interoperability vectors

`sdk_issued_public.json` was generated by the existing Node SDK fixture helper
`integration/providers/openac/tests/fixture.mjs` (`buildCredentialFixture()`)
on 2026-09-14. The Python reference parser authenticates it without calling that
SDK. It contains synthetic credential material and public keys only. Keeping the
vector here makes the regression independent of temporary directories and an
installed Node toolchain.

`independent_issuer_public.json` is a separate fixed public credential vector.
Neither file contains production credentials or private signing keys.

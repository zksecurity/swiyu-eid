# zkID wallet proof of concept

- `circom`: circuits and witness generators
- `ecdsa-spartan2`: Rust setup, proving, and verification
- `openac-sdk`: TypeScript wallet, verifier, and sidecar APIs
- `mobile`: native and Flutter bindings
- `benchmark`: reproducible runners and result files

The end-to-end explanation is in the [project overview](../../../website/index.html#zkid-stack).
